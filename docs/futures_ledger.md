# 元大期貨本日餘額：Futures_Ledger 與既有 Trade_Log

給另一個助理寫入 Google 試算表 `Quant_Database` 用。程式只讀，用跟第四頁一樣的 `gspread` `get_all_records()`（表頭名稱，不看欄位字母）。

試算表 id：`1nMpEaNcIqymaTHiqJDhMxm5gLzCWrlfk5wkpCMJMjGM`。

## 不要做的事

- 不要新建第二個交易明細分頁。成交已經在 `Trade_Log`。
- 不要改 `Trade_Log` 的表頭、順序或儲存格公式。A–R 已經是下面這組。

程式用 `get_all_records()` 的表頭名稱，不看欄位字母。`時間` 會當成成交日（也接受舊名 `成交時間`）。`種類` 與 `總金額` 保持原名：種類用來分辨期貨／選擇權／股票，總金額不拿來當出入金，也不拿來當已實現損益。

## Trade_Log 實際表頭（A–R）

| 欄 | 表頭 | 餘額計算 |
| --- | --- | --- |
| A | 時間 | 成交日。晚於校正日才計入。Sheets 序號也可以 |
| B | 帳戶 | 含「元大」才進期貨餘額。空白也視同元大 |
| C | 種類 | `台股期貨`、`台股選擇權`、`台股`、`美股`、`美股選擇權`。含「期」或「選」才計入；台股／美股略過。這欄不是開倉／平倉 |
| D | 動作 | `買進`、`賣出`、`放空`、`回補` |
| E | 標的 | 商品代號，例如 `FMF` |
| F | 名稱 | 例如 `微台`。餘額計算不讀 |
| G | 數量 | 口數 |
| H | 成交價 | 點數或價格 |
| I | 合約乘數 | 有填就用這欄。空白才用內建：TX 200、MTX 50、FMF／TMF 10、TXO 50；個股期 2000；代號 `S`+證券代號為 100 |
| J | 總金額 | 契約金額。不計入餘額，也不當成已實現損益或出入金 |
| K | 最大虧損比例 | 不讀 |
| L | 覆盤筆記 | 不讀 |
| M | 標的槓桿 | 不讀 |
| N | 類型 | 只有寫 `開倉`／`平倉` 才覆蓋動作的開平判斷。空白則：買進＝開多、放空＝開空、賣出＝平多、回補＝平空 |
| O | 長短線 | 不讀 |
| P | 停損價 | 不讀 |
| Q | 已實現損益 | 有數字就用這欄。空白才自行計算：（平倉價 − 校正均價）× 口數 × 乘數 |
| R | 交易後帳戶槓桿 | 不讀 |

N–R 可以整欄不存在，也可以空白。

Q 有數字時，不再扣預設手續費與期交稅。只有列上另外寫了 `手續費` 或 `稅` 而且有數字，才會再扣。Q 空白時才扣預設值（見下方設定列）。

股票列（種類是台股或美股）留在這張表，但不進元大期貨餘額。種類空白時仍視同衍生品。

成交日晚於校正日才計入。校正當天的成交視為已經含在校正餘額裡。

成本用平均成本。加倉重算均價；平倉超過剩餘口數的部分轉成反向新倉。起點是校正點寫的持倉均價；校正列沒填均價時，改讀 `持倉統計` 同一商品的平均成本，並在第四頁顯示提醒。

公式：

## Daily_NAV 日期

`日期` 若被存成 Sheets 序號（1899-12-30 起算，例如 46329＝2026-11-03），讀取時會轉成日期，歷史圖不會再落到 1970。寫入請用 `yyyy-mm-dd`，並把 A 欄設成日期格式 `yyyy-mm-dd`（`USER_ENTERED`）。不要寫序號。程式的 `sheet_dates.write_daily_nav` 就是這樣寫；開頁面時不會自動回寫試算表。
