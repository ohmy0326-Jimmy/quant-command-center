給另一個助理寫入 Google 試算表 `Quant_Database` 用。程式只讀，用跟第四頁一樣的 `gspread` `get_all_records()`（表頭名稱，不看欄位字母）。

試算表 id：`1nMpEaNcIqymaTHiqJDhMxm5gLzCWrlfk5wkpCMJMjGM`。

## 不要做的事

- 不要新建第二個交易明細分頁。成交已經在 `Trade_Log`。
- 不要改 `Trade_Log` 的 A–M：表頭、順序、儲存格公式都留著。
- 新欄只追加在既有欄位後面。A–M 已佔滿 13 欄時，順序就是 N–R。

這個環境讀不到私人試算表，所以 A–M 的確切表頭是用 Notion「交易日誌」（Make.com 同步進 `Trade_Log` 的那份）對出來的。程式認的是表頭名稱。多出來的既有欄（含公式）會略過，不會改。

## Trade_Log 既有欄位（A–M，不可改）

| 表頭 | 說明 |
| --- | --- |

| 帳戶 | `元大期貨`、`第一證券`、`IB`、`嘉信理財`、`投資先生`、`口袋證券` |
| 標的 | 商品代號，例如 `FMF` |
| 名稱 | 例如 `微台` |
| 商品種類 | `台股期貨`、`台股選擇權`、`台股`、`美股`、`美股選擇權` |
| 動作 | `買進`、`賣出`、`放空`、`回補` |
| 數量 | 口數或股數 |
| 成交價 | 點數或價格 |

## 只追加的欄（預期 N–R）

讀取時這五欄可以整欄不存在，也可以空白。

| 欄 | 表頭 | 格式 | 空白時 |
| --- | --- | --- | --- |
| N | 類型 | 文字。只有寫 `開倉`／`平倉` 才會覆蓋「動作」的開平判斷 | 依動作：買進＝開多、放空＝開空、賣出＝平多、回補＝平空 |
| O | 長短線 | 文字，例如 `當沖`、`波段` | 略過，不影響餘額 |
| P | 停損價 | 數字 | 略過，不影響餘額 |
| Q | 已實現損益 | 數字，新台幣。平倉價差，可含公式 | 自行計算：（平倉價 − 校正均價）× 口數 × 乘數 |
| R | 交易後帳戶槓桿 | 數字，倍 | 略過，不影響餘額 |

Q 有數字時，這筆的已實現損益就用 Q，不再扣預設手續費與期交稅。只有列上另外寫了 `手續費` 或 `稅` 而且有數字，才會再扣。Q 空白時才扣預設值（見下方設定列）。

股票列（商品種類是台股或美股）留在這張表，但不進元大期貨餘額。只計帳戶含「元大」、而且商品種類含「期」或「選」的列。商品種類空白時仍視同衍生品。

成交日晚於校正日才計入。校正當天的成交視為已經含在校正餘額裡。

成本用平均成本。加倉重算均價；平倉超過剩餘口數的部分轉成反向新倉。起點是校正點寫的持倉均價；校正列沒填均價時，改讀 `持倉統計` 同一商品的平均成本，並在第四頁顯示提醒。

公式：
