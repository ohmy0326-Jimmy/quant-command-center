# 總經週期與配置

第五頁「總經週期與配置」讀 `data/macro_cycle.json`。側邊欄順序是第一頁到第四頁、第五頁總經週期、第六頁下單輔助。格式是 `data/macro_cycle.schema.json`（JSON Schema draft 2020-12，`schema_version` 為 `1.0.0`）。載入時用 `macro_cycle.validate_macro_cycle` 檢查；檔案不在、JSON 壞掉或不符合 schema，頁面改顯示原因，第六頁的目標槓桿上限與最低現金水位暫用中性（1.5 倍、15%），不中斷其他頁。

加總與多空狀態不寫在 JSON 裡，一律用八項分數現算，避免明細和總分各寫各的。

## 版本與更新日

| 欄位 | 規則 |
| --- | --- |
| `schema_version` | 固定 `"1.0.0"`。只改分數或產業內容不必升版。欄位有破壞性變更時才升版，並同時改 schema 的 `const` 與載入程式。 |
| `score.updated_at` | `YYYY-MM-DD`。分數每週改一次，日期一起改。 |
| `score.cadence` | 固定 `"weekly"`。 |
| `industries.updated_at` | 必須是當月 12 日，形式 `YYYY-MM-12`，而且要是真實存在的日期。 |
| `industries.cadence` | 固定 `"monthly"`。 |
| `industries.as_of_day` | 固定 `12`。 |

## 八項多空分數

`score.indicators` 固定 8 筆。每筆：

| 欄位 | 規則 |
| --- | --- |
| `id` | 小寫代號，`^[a-z][a-z0-9_]*$`，不可重複。 |
| `name` | 畫面上的名稱。 |
| `score` | 整數，`-2` 到 `+2`。 |
| `example` | `true` 表示這格仍是示例，不是正式週報。 |
| `note` | 選填。示例請在文字裡寫明。 |

八項加總的範圍是 `-16` 到 `+16`。v1 對到五種狀態：

| 加總 | 狀態 |
| --- | --- |
| +9～+16 | 牛 |
| +4～+8 | 偏多 |
| -3～+3 | 中性 |
| -8～-4 | 偏空 |
| -16～-9 | 熊 |

目前種子檔八項都是示例，加總 `+1`，狀態是中性。門檻寫在 `macro_cycle.REGIME_BANDS`，不放進每週會改的 JSON。

## 二十個產業

`industries.items` 固定 20 筆。每筆：

| 欄位 | 規則 |
| --- | --- |
| `id` | 穩定代號，不可重複。 |
| `name` | 產業名稱，不可重複。 |
| `cycle` | `復甦`、`成長`、`趨緩`、`衰退`。四象限就是這四個位置：左上復甦、右上成長、右下趨緩、左下衰退。 |
| `direction` | `上行`、`持平`、`下行`。上行往下一階段（順時針）靠，下行往回靠。 |
| `stance` | `加碼`、`中性`、`減碼`。 |
| `tickers` | 至少一檔代表股。全部產業加起來，去掉大小寫與 `.TW`、`.TWO`、`.US`、`.HK` 後不可重複。`2330` 與 `2330.TW` 是同一檔。 |
| `example` | `true` 表示整列都是示例。`false` 表示立場是目前配置。 |
| `note` | 選填。立場已定、但週期／方向／代表股仍是示例時，note 要寫清楚。 |

v1 種子裡，立場已定的是：

- 加碼：半導體設備、光通訊/CPO、重電電網、先進製程
- 中性：AI 算力
- 減碼：消費電子、生技醫療、記憶體

這八列的週期、方向與代表股仍是示例。其餘十二個產業整列都是示例。

## 對到第六頁的風控

只覆寫兩個既有欄位，使用者仍可在「風控規則設定」裡改，工作階段會留著。按「改回總經週期預設」會再帶入一次。

| 狀態 | 目標槓桿上限 | 最低現金水位 |
| --- | --- | --- |
| 牛 | 2.0 倍 | 10% |
| 偏多 | 1.8 倍 | 12% |
| 中性 | 1.5 倍 | 15% |
| 偏空 | 1.2 倍 | 22% |
| 熊 | 1.0 倍 | 30% |

對應畫面「目標槓桿上限（倍）」與「最低現金水位（%）」。第二階段槓桿不跟著改。

持倉代號用代表股對到產業。對得上才在代號旁邊顯示「產業 · 加碼／中性／減碼」；整列是示例的會再加上「（示例）」。對不上的不標。

## 怎麼改資料

1. 每週：改 `score.indicators` 的分數與 `score.updated_at`。正式採用後把該項 `example` 設為 `false`。
2. 每月 12 日：改 `industries.items`，並把 `industries.updated_at` 設成當天（必須是 12 日）。
3. 不要自加總分欄位。存檔後重新整理戰鬥艙；已開著的第六頁若要改回新預設，按「改回總經週期預設」。
