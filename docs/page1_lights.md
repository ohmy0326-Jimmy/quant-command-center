既有五項計分（VIX、10 年名目殖利率、外資、美元／台幣、加權）仍由 `macro_risk.py` 計算，Telegram 宏觀燈用的還是這個分數。這批新增的燈只顯示，不新增推播種類，也不改黃燈／紅燈的推播政策。回撤煞車仍是 −8% 黃、−12% 紅。

## 有約定門檻

| 指標 | 來源 | 單位 | 燈 |
| --- | --- | --- | --- |
| 美國 10 年實質利率 | FRED `DFII10` | 百分點 | 達到 2.5 黃、達到 3.0 紅。低於 2.5 且資料正常才是綠。 |

資料超過 3 個工作日，或整段抓不到，狀態是未知。

抓取先看網頁服務 `quant-command-center` 的環境變數 `FRED_API_KEY`（或同名 Streamlit secret）。有金鑰就走 FRED 官方 API，失敗或沒有金鑰再走公開 CSV `fredgraph.csv`。公開 CSV 不需要金鑰；2026-11-12 從一般網路可以讀到 DFII10。連不上時畫面寫原因：公開 CSV 連不上、回傳的不是數值，或官方 API 的 HTTP 狀態。沒有金鑰會另外寫「這個服務沒有 FRED_API_KEY」。原因不含金鑰內容。缺值仍是未知，不算 0 分，也不進 Telegram 分數。第五頁自動項走同一條抓取。
