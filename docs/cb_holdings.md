# 可轉債與 CBAS 持倉

第四頁、情境模擬與 `GET /v1/portfolio` 共用 `finalize_valuation`。這一頁只讀 `持倉統計`，不寫回、不下單。

`Active_Positions` 不用加欄。可轉債市值加在該列「帳戶」對應的帳戶淨值上：證券帳戶是現金＋市值−借款；若列在元大期貨，市值加進權益數。請把部位放在實際持有的帳戶。

## 種類

| `種類` | 商品 |
| --- | --- |
| `可轉債`、`CB`、`轉換公司債` | 可轉債（CB） |
| `可轉債資產交換`、`CBAS`、含「資產交換」 | CBAS |

CBAS 要先認，因為字樣裡也有「可轉債」。

## 既有欄位怎麼填

| 欄 | 填法 |
| --- | --- |
| `標的` | 債券代號（例如五碼 `13164`）。不要拿來當股價。 |
| `持有數量` | 張數。空單用負數。 |
| `平均成本` | 百元報價。若填的是每張台幣市價（大於 3000），會除以「面額／100」換回百元報價。 |
| `標的槓桿` | 可轉債／CBAS 忽略，曝險不再乘這格。 |

`投入總金額` 可以空白。成本用平均成本 ×（面額／100）× 張數。損益不含 0.3% 證交稅。

## 要另外加的欄

沒有這些欄也能列出部位，但沒有轉換價值時名目曝險是 0（市值仍進淨值）。

| 欄 | 必填？ | 說明 |
| --- | --- | --- |
| `百元報價` | 建議 | 市價。有這欄就用它；否則用 `即時報價`；再沒有才用平均成本。債券沒有 Yahoo 報價。 |
| `轉換價格` | 要算轉換價值就必填 | 每股轉換價，和股價同一單位（元／股）。 |
| `標的代號` | 建議 | 標的股票，例如 `2330` 或 `2330.TW`。空白且 `標的` 是四碼股票才會把 `標的` 當成股票；五碼債碼不會。 |
| `標的現價` 或 `標的股價` | 沒抓到股價時要填 | 空白時，戰情室與 API 用 `標的代號` 向 Yahoo 抓現股。 |
| `面額` | 否 | 每張面額，預設 `100000`。1 點百元報價 = 面額／100（預設 1,000 元）。 |
| `Delta` | 否 | 每張可轉換股數的比例。有填就用，不再估算。 |
| `純債價值` | 否 | 百元報價。有填時，可轉債 Delta 改用（轉換價值−債底）／（市價−債底），市價沒有高於債底則 Delta 為 0。 |
| `標的Beta` 或 `Beta值` | 否 | 套在 Delta 曝險上的 Beta。都沒有就暫用 1，並在 Beta 來源註明。 |
| `波動率`、`到期日` | 僅 CBAS、且沒填 Delta 時 | 有這兩欄才用 Black-Scholes 買權 Delta。波動率 `0.2` 或 `20` 都可以（大於 3 視為百分數）。`利率` 空白當 0，不另假設利率曲線。 |

`到期日` 若早於今天，整列會像選擇權一樣被排除。

## 怎麼進槓桿、Beta、現金

- **市值** = 百元報價 ×（面額／100）× 張數。進淨值，跟現股一樣是已經付出的部位，不是期貨保證金。
- **轉換價值（百元）** = 股價／轉換價格 × 100。整筆台幣 = 股價 ×（面額／轉換價格）× 張數。
- **名目曝險** = \|Delta × 整筆轉換價值\|。Beta 曝險再乘標的 Beta。不加標的槓桿。
- 可轉債沒有 Delta 時：有純債價值用債底法，否則用 min(1, 轉換價值／市價)，來源寫「估算」。
- CBAS 沒有 Delta、也沒有波動率與到期日時，名目曝險是 0，第四頁會警告。權利金市值仍在淨值裡。
- 現金水位仍是帳戶現金（可轉債買進時已從現金扣掉）。不把 CB 和 CBAS 互相抵銷，也不做台股對美股或其他跨市場對沖。
- 情境模擬：市值留在淨值，價格衝擊用 Beta 曝險 × 該市場報酬（台股用加權、種類含「美」用費半因子）。這是同一套線性 Delta，不是新的避險單。
